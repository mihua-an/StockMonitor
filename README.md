# StockMonitor

台股與美股的桌面即時看盤程式，Windows 上執行。

- 行情：逐筆成交、五檔、走勢、K 棒與技術分析
- 大單流向、價量分布、事件提示
- 歷史回放：逐秒重播收盤後的交易日
- 模擬下單與帳務管理
- 盤中機器學習模型預測（模型需自行訓練，不隨專案提供）

由 Electron、Python（FastAPI）與 Rust 組成：Rust 負責行情寫入與分析，Python 負責券商連線與 API，Electron 負責畫面。

## 需要什麼

- Windows 10 1903 以上或 Windows 11，x64
- 券商帳號與 API 權限（自行申請）：
  - 永豐金證券 Shioaji：台股、台指期
  - 富途 moomoo：美股，並需安裝官方 OpenD
- 券商 SDK 需自行安裝，本專案不提供

本專案不提供任何行情資料、券商憑證或訓練好的模型。

## 安裝與執行

需要先安裝：Node.js 24、Python 3.14、Rust（版本見 `native/*/rust-toolchain.toml`）。

從原始碼建出 Windows 安裝包：

```powershell
npm run release
```

完成後執行 `dist\StockMonitor Setup <version>.exe` 安裝。第一次建置會下載相依套件，約需 10 分鐘；所有下載都以版本與雜湊鎖定。

安裝後：

1. 開啟「設定 → 券商帳號」，安裝 Shioaji、moomoo-api，並填入自己的 API 金鑰。
2. 使用富途來源時，另外安裝並登入官方 OpenD（預設 `127.0.0.1:11111`）。
3. 想在收盤後看到沒訂閱過的股票的五檔與漲跌停，可在「設定 → 資料儲存 → 收盤資料來源」自行設定資料來源，使用前請自行確認資料提供者的條款。沒有設定就不會連線。

程式未做程式碼簽章，Windows SmartScreen 第一次執行時會警告，按「其他資訊 → 仍要執行」。
